## التركيب (خطوة بخطوة)

### 1) إعداد التطبيق في Discord Developer Portal
افتح https://discord.com/developers/applications واختر تطبيقك:
1. **Bot** ← فعّل ✅ **Server Members Intent** و ✅ **Message Content Intent** ← انسخ **Token**.
2. **General Information** ← انسخ **Application ID** (هو الـ CLIENT_ID).
3. **OAuth2** ← انسخ **Client Secret**.
4. **OAuth2 ← Redirects** ← أضف بالضبط:
   `http://localhost:3000/auth/callback`
   (لو أونلاين: `https://دومينك/auth/callback`)

### 2) تجهيز المشروع
```bash
npm install
cp .env.example .env     # ويندوز: copy .env.example .env
```
افتح `.env` واملأ: `TOKEN` و `CLIENT_ID` و `CLIENT_SECRET` و `SESSION_SECRET` (أي نص عشوائي طويل).

### 3) التشغيل
```bash
npm start
```
افتح **http://localhost:3000** ← سجل دخول ← اختر السيرفر ← أضف البوت لو ما هو موجود.

> ⚠️ افتح اللوحة دايماً بنفس الرابط اللي في `BASE_URL` (مثلاً localhost وليس 127.0.0.1) وإلا تسجيل الدخول والحفظ ما يشتغلون.

### 4) أول ما يدخل البوت
- ارفع **رتبة البوت** فوق الرتب اللي بيعطيها/يشيلها.
- لو تبي الأوامر تظهر فوراً أثناء التجربة: حط `GUILD_ID` في `.env`.

## الاستضافة أونلاين
- ارفع المجلد (بدون `node_modules` و `data`) لاستضافة Node.js (VPS / Railway / Render ...).
- غيّر `BASE_URL` لرابط موقعك (`https://...`) وأضف نفس الرابط في Redirects.
- شغّل `npm install` ثم `npm start`.
- **مهم:** احتفظ بمجلد `data/` (فيه كل الإعدادات والخبرة) ولا تحذفه عند التحديث.
- لو الاستضافة تحذف الملفات عند كل تشغيل (استضافة بدون تخزين دائم) اختار استضافة فيها Volume.

## ملاحظات مهمة على الميزات الجديدة
- **من نفّذ العملية** و**سلة الاستعادة** يحتاجون صلاحية **View Audit Log** (موجودة في رابط الدعوة). لو أضفت البوت قبل التحديث أعد إضافته من اللوحة أو أعطه الصلاحية يدوياً.
- **تتبع الدعوات** يحتاج صلاحية **Manage Server** (أضفتها لرابط الدعوة). بدونها يظهر «غير معروفة».
- استعادة الرتبة: لازم رتبة البوت أعلى من الرتبة المستعادة لتتوضع مكانها، والصلاحيات اللي ما يملكها البوت تُتجاهل (ويُبلغك بذلك).
- زر **→ رجوع** موجود في كل صفحات اللوحة.

## الأمان
- اللوحة تعرض لكل مستخدم فقط السيرفرات اللي عنده فيها **Manage Server** أو **Administrator**.
- كل التعديلات تتحقق من الصلاحية في السيرفر (مو بس في الواجهة).
- الحماية من CSRF (طلبات JSON فقط + فحص المصدر) وكوكي httpOnly.
- لا تشارك `.env` مع أي أحد، ولو تسرب التوكن أو الـ Secret أعد توليده فوراً.

## هيكل المشروع
```
src/index.js            نقطة التشغيل (بوت + موقع)
src/defaults.js         الإعدادات الافتراضية لكل وحدة
src/db.js               قاعدة البيانات (ملف JSON في data/)
src/bot/commands/       أوامر السلاش
src/bot/events/         أحداث ديسكورد
src/bot/modules/        منطق الأنظمة (automod, tickets, leveling ...)
src/web/server.js       لوحة التحكم + OAuth2 + API
public/                 واجهة اللوحة (HTML/CSS/JS)
```

## كيف تضيف إعداد جديد؟
1. أضف المفتاح في `src/defaults.js`.
2. أضف الحقل في `public/modules.js` (النماذج تتبني تلقائياً).
3. استخدمه في البوت عبر `db.cfg(guildId).اسم_الوحدة`.
